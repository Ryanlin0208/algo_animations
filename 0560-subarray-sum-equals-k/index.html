02 / 同步程式碼PYTHON
原理說明：為什麼先查詢再更新？
兩個前綴和的差，就是中間的總和。
若目前前綴和是 prefix，要找總和為 k 的連續子陣列，就找先前有多少個前綴和等於 prefix − k。每次出現都代表一個不同起點，所以必須累加次數。
先查詢，再把目前 prefix 寫入表中。若反過來，k = 0 時會把目前前綴和自己配對，錯算長度為 0 的子陣列。
負數與零都適用，不需要排序。原始演算法平均時間 O(n)、額外空間 O(n)；動畫另外保存步驟與索引供回放。
