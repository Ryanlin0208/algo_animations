02 / 同步程式碼PYTHON
原理說明：為什麼搜尋這個範圍？
至少裝得下最重的一件。
left = max(weights)，right = sum(weights)。下界確保每一件都能裝上船，上界能在一天內送完。
給定 mid 後，依原順序盡量裝滿每天的船。下一件會超重時，先增加 days_needed，再把 current 清零，最後裝入該件。
days_needed ≤ days 時，保存 ans = mid，往更小的載重搜尋；否則提高 left。載重增加不會讓所需天數增加，因此可以二分搜尋。
時間 O(n log S)，S = sum(weights)，輔助空間 O(1)。動畫另存快照。支援 1–20 件、每件 1–100，1 ≤ days ≤ 件數。
