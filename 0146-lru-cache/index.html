02 / 同步程式碼PYTHON
原理說明：為什麼需要兩種結構？
查找靠 cache，順序靠雙向串列。
cache 將 key 對應到節點，平均 O(1) 查到資料。remove 使用節點的 prev、next 直接摘下節點；insert 將它接到 right 前方成為 MRU。
get 命中後也算一次使用，會重新插到 MRU；未命中回傳 −1，順序不變。put 更新現有 key 時，這份程式會移除舊節點並建立新節點。
容量超限時，left.next 就是 LRU，須同時從串列和 cache 移除。哨兵不算容量；操作完成時兩種結構的有效項目一致。
get / put 平均 O(1)，空間 O(capacity)。動畫另外保留逐行快照與歷史節點。
