02 / 同步程式碼PYTHON
原理說明：為什麼使用堆疊？
最內層的括號會最先完成。
遇到 [ 時，把目前字串和數字存進 stack，然後清空累積變數。遇到 ] 時，彈出最近保存的狀態，計算 previous_string + current_string * repeat。
例如 3[a2[c]]：先展開 2[c] 得到 cc，接回 a 成為 acc，最後重複三次。
多位數用 current_number * 10 + int(char) 累積。右括號分支不重設 current_number；本動畫保留原始程式的變數更新方式。
掃描 n 個字元；實際時間還包含每次字串串接和重複所複製的字元，不能只算 O(n)。堆疊保存各層狀態，輸出也需要對應長度的空間。
動畫限制：輸入 1–80 字元、正整數重複次數 1–300，展開最多 2,000 字元。僅接受英文字母及有效的 k[字串] 結構。
