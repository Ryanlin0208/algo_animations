02 / 同步程式碼PYTHON
原理說明：為什麼暫扣上一輪字元？
讓剛使用的字元不參與下一次 pop。
heapq 是最小堆積，儲存 (-freq, char) 就能先取出出現最多的字元。負頻率相同時，Python tuple 會按字母排序。
每輪先 pop 並加入 ans，再放回上輪的剩餘字元，最後更新 prev_count、prev_char。這個順序避免連續取到相同字元。
放回後、覆寫暫存前，畫面上的舊暫存變數仍有值；它不是另一份字元。兩個 prev 變數分兩行更新，動畫也保留這個中間狀態。
若堆積已空而 ans 長度不足，就回傳空字串。圖上保留的 ans 是部分結果，不是回傳值。
n 為字串長度，k 為不同字元數。時間 O(n log k)（k = 1 時 O(n)），不含答案的輔助空間 O(k)。動畫支援 1–30 個小寫字母。
