02 / 同步程式碼PYTHON 

          

            
              原理說明：為什麼 taken == numCourses 就代表沒有循環？
            
            
永遠先修「已經沒有先修限制」的課。

            

              indeg[a]：課 a 還有幾堂先修課沒修。等於圖上指向 a
              的箭頭數量。
            

            

              indeg 為 0
              的課可以直接修，放進佇列。每修掉一堂課，就把它指出去的箭頭拿掉：下游課的
              indeg 減 1，減到 0 就換它排隊。
            

            

              如果課程之間有循環，例如 1 → 2 → 3 →
              1，循環裡每堂課都在等另一堂，indeg
              永遠不會歸零，也就永遠進不了佇列。
            

            

              所以最後修到的課數 taken 少於
              numCourses，就代表有課被循環卡住，回傳 False。
            

            

              每堂課進出佇列一次、每條箭頭處理一次：時間 O(V + E)，空間 O(V +
              E)。
