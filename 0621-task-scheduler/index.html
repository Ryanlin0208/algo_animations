02 / 同步程式碼PYTHON
原理說明：為什麼每輪計 n + 1？
同輪用過的任務，先放進 temp。
每輪優先取出最多次的任務，最多執行 n + 1 種。用過但仍有剩餘的頻率暫存，整輪結束才放回堆積，因此不會在同輪取到同一種類。
放回後 heap 仍非空，就計入完整 n + 1 時槽，不足的部分是 idle。若 heap 已空，只需增加 used，最後不用額外等待冷卻。
heap 只有數字，無法從這份程式直接還原任務字母的排程；本動畫忠實顯示工作／idle 與頻率狀態。
已補上原程式缺少的 import heapq。T 為任務數，k 為種類數，時間 O(T log k)（k = 1 時 O(T)），演算法輔助空間 O(k)；動畫另存快照。
輸入限制：1–30 個 A–Z 任務，冷卻 n 為 0–10。
