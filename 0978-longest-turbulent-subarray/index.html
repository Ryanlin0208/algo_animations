02 / 同步程式碼PYTHON 

          

            原理說明：up 和 down 代表什麼？
            
震盪就是折線一上一下、不能連續同方向。

            

              up：以 arr[i] 結尾、而且最後一步是上升（arr[i] >
              arr[i − 1]）的最長震盪子陣列長度。
            

            

              down：以 arr[i] 結尾、而且最後一步是下降的最長長度。
            

            

              這一步上升時，前一步必須是下降，所以新的 up 是舊的 down 加
              1；同時「以下降結尾」的鏈不可能結束在一個上升步，只剩 arr[i]
              自己，down 歸 1。下降時左右對調；相等時兩條鏈都斷。
            

            

              Python 的 up, down = down + 1, 1
              是同時賦值：右邊先用舊值算完再一起寫入，所以不會用到剛更新的 up。
            

            
時間 O(n)，空間 O(1)。
