            原理說明：為什麼可以變成子集合問題？
            
把加號的數字放一組，減號的放另一組。

            

              設正號組總和 P、負號組總和 N。P − N = target，P + N =
              total，相加得 P = (total + target) / 2。只要數「總和恰好為 P
              的子集合」有幾個，就是答案。
            

            

              P 必須是非負整數：|target| > total 或 total + target
              為奇數時，直接回傳 0。
            

            

              每個數字只能用一次，所以 s 由右往左掃。更新 dp[s] 時，dp[s − x]
              還沒被這一輪改過，代表「不含 x」的方法數；若由左往右，x
              會被重複使用。
            

            

              nums 裡的 0：x = 0 時 dp[s] += dp[s]，每個方法數翻倍，對應 +0 與
              −0 兩種寫法。
